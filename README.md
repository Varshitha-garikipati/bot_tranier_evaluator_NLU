# 📘 Annotation and ChatBot Training Toolkit
![Status](https://img.shields.io/badge/Project-Active-brightgreen)
![Tech](https://img.shields.io/badge/Tech-Node.js-blue)
![Python](https://img.shields.io/badge/Python-Supported-yellow)
![Contributions](https://img.shields.io/badge/Contributions-Welcome-orange)

A complete toolkit for **annotating NLU data** (intents, entities, tokens) and **training chatbot models**.

---

## 🌟 Key Features
- Annotation Tool – Mark intents, entities, tokens
- Chatbot Training Pipeline
- JSON/YAML annotation storage
- Node.js backend + optional Python scripts
- Modular structure

## ⚙️ Installation
```
git clone https://github.com/n1hal06/Annotation-and-ChatBot-Training-.git
cd Annotation-and-ChatBot-Training-
npm install
pip install -r requirements.txt   # optional
```

---

## ▶️ Run the Project
Start backend:
```
node server.js
```

Open UI:
```
index.html
```

---

## 🤖 Train the Chatbot
```
node train.js
# or
python train.py
```

---

## 🧪 Tests

python nlu_tests/app_test.py
